\section*{แผนบริหารการสอนประจำบทที่ 1}
\addcontentsline{toc}{section}{แผนบริหารการสอนประจำบทที่ 1}

\begin{planbox}{หัวข้อเนื้อหาประจำบท}
\begin{enumerate}
    \item ปัญหาโรคใบทุเรียนสำคัญทางเศรษฐกิจและพยาธิวิทยาพืช
    \item สถาปัตยกรรมการเรียนรู้เชิงลึก MobileNetV3 และ Transfer Learning
    \item การออกแบบไปป์ไลน์การเตรียมข้อมูลภาพและการเพิ่มพูนข้อมูล
    \item การตีความการตัดสินใจของปัญญาประดิษฐ์ด้วย Grad-CAM
    \item การส่งออกโมเดลสู่สถาปัตยกรรม Edge AI และแอปพลิเคชันสำหรับเกษตรกร
\end{enumerate}
\end{planbox}

\begin{planbox}{วัตถุประสงค์เชิงพฤติกรรม}
\begin{enumerate}
    \item อธิบายลักษณะรอยโรคและเชื้อสาเหตุของใบทุเรียนได้อย่างถูกต้อง
    \item สร้างโครงข่ายประสาทเทียมด้วย PyTorch สำหรับจำแนกภาพได้อย่างแม่นยำ
    \item ประยุกต์ใช้เทคนิค Grad-CAM ในการตรวจสอบตำแหน่งรอยโรคได้อย่างสมบูรณ์
    \item ส่งออกโมเดลเป็นมาตรฐาน ONNX และประเมินผลการทำงานได้อย่างถูกต้อง
\end{enumerate}
\end{planbox}

\newpage

\begin{planbox}{กิจกรรมการเรียนการสอน}
\begin{enumerate}
    \item บรรยายเชิงทฤษฎีพยาธิวิทยาพืชและการประมวลผลภาพดิจิทัล
    \item ฝึกปฏิบัติการโหลดชุดข้อมูลและเทรนโมเดลบน Google Colab ด้วย GPU
    \item การวิเคราะห์ภาพถ่ายใบทุเรียนจริงจากแปลงทดลองและประเมินค่าความแม่นยำ
\end{enumerate}
\end{planbox}

\begin{planbox}{สื่อการเรียนการสอน}
\begin{enumerate}
    \item เอกสารคำสอนและคู่มือปฏิบัติการระบบตรวจจับโรคใบทุเรียน
    \item โน้ตบุ๊ก Google Colab พร้อมชุดข้อมูลภาพใบทุเรียนและคลังโค้ด PyTorch
    \item สไลด์บรรยายสถาปัตยกรรม MobileNetV3 และระบบ Explainable AI
\end{enumerate}
\end{planbox}

\begin{planbox}{การประเมินผล}
\begin{enumerate}
    \item ประเมินจากการมีส่วนร่วมในการอภิปรายและตอบคำถามในชั้นเรียน
    \item ประเมินจากผลลัพธ์การฝึกปฏิบัติการเทรนโมเดลและการเขียนสคริปต์
    \item ประเมินจากความถูกต้องของรายงานผลการวินิจฉัยโรคใบทุเรียน
\end{enumerate}
\end{planbox}

\section{สถาปัตยกรรมโครงข่ายประสาทเทียม MobileNetV3}

\section{ระบบตีความและชี้ตำแหน่งรอยแผลด้วย Grad-CAM}

ความน่าเชื่อถือทางวิทยาศาสตร์ในการวินิจฉัยโรคพืช ต้องสามารถตรวจสอบได้ว่าโมเดลตัดสินใจจากลักษณะของรอยโรคจริง ไม่ใช่เกิดจากการจดจำฉากหลังหรือแสงสะท้อน เทคนิค Gradient-weighted Class Activation Mapping (\textbf{Grad-CAM}) ทำการคำนวณเกรเดียนต์ของคลาสเป้าหมายเทียบกับ Feature Map ในเลเยอร์สังเคราะห์สุดท้ายของ Convolution เพื่อสร้างแผนที่ความร้อน (Heatmap) ซ้อนทับบนภาพใบไม้จริง

\begin{academicbox}{หลักการคำนวณน้ำหนักความสำคัญของ Grad-CAM}
ค่าน้ำหนักความสำคัญ $\alpha_k^c$ ของ Feature Map ที่ $k$ สำหรับคลาสโรค $c$ คำนวณได้จาก:
\[
\alpha_k^c = \frac{1}{Z} \sum_{i} \sum_{j} \frac{\partial Y^c}{\partial A_{i,j}^k}
\]
โดยที่ $Z$ คือจำนวนพิกเซลใน Feature Map, $Y^c$ คือค่าคะแนนก่อนเข้าฟังก์ชัน Softmax ของคลาส $c$, และ $A_{i,j}^k$ คือค่าแอกติเวชันที่ตำแหน่ง $(i, j)$ ของ Feature Map ที่ $k$
\end{academicbox}

\section{การส่งออกโมเดลเพื่อการประยุกต์ใช้ในแปลงเกษตรจริง}

เพื่อให้เกษตรกรสามารถนำระบบไปใช้งานในสวนทุเรียนที่อาจไม่มีสัญญาณอินเทอร์เน็ต โครงสร้างโมเดล PyTorch จะถูกแปลงให้อยู่ในรูปแบบ Open Neural Network Exchange (\textbf{ONNX}) ซึ่งรองรับการประมวลผลบนสมาร์ทโฟนระบบปฏิบัติการ Android และ iOS ผ่านเฟรมเวิร์ก Flutter รวมทั้งรองรับการทำงานบนบอร์ดสมองกลฝังตัว เช่น Raspberry Pi 4/5 และ NVIDIA Jetson Nano ในการติดตั้งบนรถตัดหญ้าอัตโนมัติหรือโดรนสำรวจแปลง

\section*{คำถามทบทวนท้ายบทที่ 1}
\addcontentsline{toc}{section}{คำถามทบทวนท้ายบทที่ 1}
\begin{enumerate}
    \item จงอธิบายความแตกต่างของรอยแผลระหว่างโรคใบติดและโรคใบจุดสาหร่ายในเชิงพยาธิวิทยาพืช
    \item เหตุใดสถาปัตยกรรม MobileNetV3 จึงเหมาะสมกับการพัฒนาเป็นแอปพลิเคชันสำหรับเกษตรกรมากกว่าสถาปัตยกรรม ResNet152
    \item เทคนิค Grad-CAM มีบทบาทอย่างไรในการยืนยันความถูกต้องของการวินิจฉัยโรคพืชด้วยปัญญาประดิษฐ์
    \item จงสรุปขั้นตอนการแปลงไฟล์โมเดลจาก PyTorch (.pth) ไปเป็นมาตรฐาน ONNX สำหรับใช้งานบนอุปกรณ์พกพา
\end{enumerate}
