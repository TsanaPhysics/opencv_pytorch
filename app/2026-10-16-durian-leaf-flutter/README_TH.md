# หมอใบทุเรียน — แอป Flutter (รุ่น 1.0.0 · 2026-10-16)

แอปมือถือ Android / iOS ตรวจโรคใบทุเรียน 4 กลุ่ม (ใบจุดสาหร่าย ใบติด ใบจุดสนิม/ใบจุดทั่วไป ใบปกติ)
ใช้โมเดล MobileNetV3-Small ชุดเดียวกับเว็บแอปและ APK (ไฟล์ `assets/model/app_model.onnx`) ทำงานออฟไลน์ทั้งหมด

## ความสามารถ
| หน้าจอ | ทำอะไร |
|---|---|
| ตรวจใบ | ถ่ายรูป · เลือกจากคลังรูป · รูปตัวอย่าง 4 รูป · ผลตรวจพร้อมความมั่นใจ แผนที่ Grad-CAM แนวทางจัดการ สภาพอากาศเสี่ยง |
| ตรวจแบบสด | เปิดกล้องวิเคราะห์ต่อเนื่อง ~4 ครั้ง/วินาที เฉพาะกรอบกลางจอ ค่าเฉลี่ยกันกระพริบ ป้าย "ผลคงที่" เตือนแสงน้อย/จ้า สลับกล้อง และปุ่มบันทึกผล |
| ประวัติ | เก็บผล 50 รายการล่าสุดในเครื่อง แตะดูผลเต็มได้ ล้างทั้งหมดได้ |
| เกี่ยวกับ | วิธีทำงาน ผลทดสอบโมเดล ข้อควรรู้ ผู้จัดทำ |

เกณฑ์ความมั่นใจเหมือนเว็บแอป: สูง ≥ 85% (และห่างอันดับสอง ≥ 30) · ปานกลาง ≥ 60% · ต่ำ < 60% (ไม่แสดงคำแนะนำสารเคมี ให้ถ่ายใหม่)

## เริ่มต้น (ทำครั้งเดียว)
1. ติดตั้ง Flutter 3.22 ขึ้นไป และ Android Studio (สำหรับ Android SDK) → ตรวจด้วย `flutter doctor`
2. เปิด Terminal ที่โฟลเดอร์นี้ แล้วรัน
   ```bash
   ./setup.sh
   ```
   สคริปต์จะ: สร้างโฟลเดอร์ `android/` `ios/` ด้วย `flutter create` → ตั้งชื่อแอปภาษาไทย สิทธิ์กล้อง minSdk 24 ไอคอน ข้อความขอสิทธิ์ iOS (`tool/setup_platforms.dart`) → `flutter pub get`
   (Windows: รัน 3 คำสั่งใน `setup.sh` ทีละบรรทัด)
3. ทดสอบตรรกะ (ไม่ต้องใช้มือถือ): `flutter test`

## รันบนมือถือ Android
- เปิด "ตัวเลือกสำหรับนักพัฒนา" + "USB debugging" บนมือถือ ต่อสาย USB แล้วรัน `flutter run --release`
- ⚠️ ใช้ **มือถือจริง** (ARM) — แพ็กเกจ onnxruntime สำหรับ Flutter มีไลบรารีเฉพาะ arm32/arm64 จึงรันบน Android emulator แบบ x86 ไม่ได้

## สร้างไฟล์ติดตั้ง APK
```bash
flutter build apk --release --split-per-abi
```
ไฟล์ที่ใช้กับมือถือส่วนใหญ่: `build/app/outputs/flutter-apk/app-arm64-v8a-release.apk`
(ค่าเริ่มต้นลงนามด้วยกุญแจทดสอบของ Flutter — ใช้ทดสอบ/แจกภายในได้ ถ้าจะออกรุ่นจริงให้ตั้งค่ากุญแจตามคู่มือ Flutter "Build and release an Android app")

## iOS
```bash
cd ios && pod install && cd ..
open ios/Runner.xcworkspace
```
เลือกทีม (Signing & Capabilities) แล้วกด Run (iOS 13 ขึ้นไป)

## โครงสร้างโค้ด
| ไฟล์ | หน้าที่ |
|---|---|
| `lib/src/classifier.dart` | โหลด ONNX และรันโมเดล (onnxruntime ผ่าน dart:ffi, รันใน isolate) |
| `lib/src/image_prep.dart` | เตรียมภาพ: หมุนตาม EXIF ย่อ 224×224 normalize · แปลงเฟรมกล้อง YUV420/BGRA → เทนเซอร์ |
| `lib/src/disease.dart` | ชื่อโรคไทย เชื้อสาเหตุ แนวทางจัดการ เกณฑ์ความมั่นใจ |
| `lib/src/history_store.dart` | เก็บประวัติในโฟลเดอร์ของแอป |
| `lib/src/ui/` | หน้าจอ: ตรวจใบ ผลตรวจ ตรวจแบบสด ประวัติ เกี่ยวกับ และตัววาด Grad-CAM |
| `tool/setup_platforms.dart` | ปรับไฟล์ Android/iOS หลัง `flutter create` |

โมเดล: input `image` [1,3,224,224] (RGB, ÷255, ลบ mean หาร std ของ ImageNet) → output `probabilities` [1,4] และ `cam` [1,7,7]
ลำดับคลาส: Algal Leaf Spot, Healthy, Leaf Blight, Leaf Spot

## สถานะการทดสอบ
- โค้ด Dart ผ่านการตรวจไวยากรณ์ และตรวจการเรียกใช้ API กับซอร์สโค้ดจริงของแพ็กเกจ onnxruntime 1.4.1 / image 4.x / camera 0.11
- ตรรกะหมุนภาพจากเซนเซอร์ (0/90/180/270°) ตรวจด้วยการจำลองแล้ว
- **ยังไม่ได้คอมไพล์และรันบนอุปกรณ์จริง** (เครื่องที่จัดทำไม่มี Flutter SDK) — ครั้งแรกให้รัน `flutter analyze` และ `flutter test` แล้วทดสอบโหมดสดบนมือถือจริง โดยเฉพาะ iOS (ทิศทางภาพจากกล้อง)
