# หมอใบทุเรียน — แอปตรวจโรคใบทุเรียนบนมือถือ (รุ่น 2026-10-16)

เว็บแอป (PWA) ภาษาไทย ใช้โมเดล MobileNetV3-Small ที่ฝึกจาก `dataset/` ประมวลผลในเครื่องด้วย ONNX Runtime Web (ไม่ส่งรูปขึ้นอินเทอร์เน็ต)

## ความสามารถ
- ถ่ายรูปด้วยกล้องมือถือ หรือเลือกจากคลังรูป / มีรูปตัวอย่าง 4 รูปจากชุดทดสอบ
- **โหมดตรวจแบบสด (Live)**: เปิดกล้องแล้ววิเคราะห์ต่อเนื่อง ~3–5 ครั้ง/วินาที เฉพาะกรอบสี่เหลี่ยมกลางจอ แสดงชื่อโรค ความมั่นใจ (เฉลี่ยถ่วงน้ำหนักกันกระพริบ) ป้าย "ผลคงที่" เมื่อทายตรงกัน 5 ครั้งติด แผนที่ Grad-CAM ซ้อนบนภาพ เตือนแสงน้อย/จ้า สลับกล้องหน้า-หลัง และปุ่ม "บันทึกผลภาพนี้" เพื่อวิเคราะห์ภาพนิ่งเต็มขั้นตอนและเก็บลงประวัติ
- แสดงโรค ความมั่นใจ (เกณฑ์ 60% / 85%) ความน่าจะเป็นทั้ง 4 กลุ่ม เชื้อสาเหตุ แนวทางจัดการ สภาพอากาศที่เสี่ยง
- แผนที่ Grad-CAM (คำนวณในโมเดล ONNX โดยตรง) ปรับความเข้มได้
- เตือนให้ถ่ายใหม่เมื่อความมั่นใจต่ำ และไม่แสดงคำแนะนำสารเคมีในกรณีนั้น
- ประวัติการตรวจ 30 รายการล่าสุด เก็บในเครื่อง
- ติดตั้งเป็นแอปและใช้งานออฟไลน์ได้ (เมื่อเปิดผ่าน HTTPS หรือ localhost)

## ผลทดสอบ
- ทดสอบในเบราว์เซอร์ (Chromium จอ 390×844) กับรูปชุดทดสอบ 34 รูป: ถูก 32/34 ตรงกับผลของ PyTorch ทุกรูป (ความน่าจะเป็นต่างกันไม่เกิน 0.035 จากวิธีย่อภาพ)
- เวลาประมวลผลประมาณ 25 มิลลิวินาที/รูป บนเครื่องทดสอบ (มือถือจริงอาจช้ากว่า)

## ติดตั้งบนมือถือ Android (APK)
ไฟล์ `2026-10-16-durian-leaf-app.apk` (18.6 MB, รุ่น 1.1.0) — Android 7.0 ขึ้นไป ทำงานออฟไลน์ทั้งหมด
1. ส่งไฟล์ APK เข้ามือถือ (LINE, Google Drive, สาย USB)
2. แตะไฟล์ → อนุญาต "ติดตั้งแอปที่ไม่รู้จัก" ให้แอปที่ใช้เปิดไฟล์ → ติดตั้ง
3. ถ้า Play Protect เตือนว่าเป็นแอปที่ไม่รู้จัก ให้เลือก "ติดตั้งต่อ" (แอปนี้ไม่ได้มาจาก Play Store)
4. เปิดแอป "หมอใบทุเรียน" → ถ่ายรูป/คลังรูป/ตรวจแบบสด (แอปขอสิทธิ์กล้องครั้งแรกที่ใช้โหมดสดหรือปุ่มถ่ายรูป ถ้าไม่อนุญาตยังใช้คลังรูปได้)
5. รุ่นใหม่ติดตั้งทับรุ่นเดิมได้ (ลงนามด้วยกุญแจเดียวกัน) ประวัติการตรวจยังอยู่

สร้าง APK ใหม่ (Ubuntu): `apt install aapt apksigner zipalign android-sdk-platform-23 dalvik-exchange` แล้วรัน `_source/android/build_apk.sh` (แก้ path ในสคริปต์ให้ตรงเครื่อง)

⚠️ `_source/android/signing/` มีกุญแจลงนามแอป (`.jks` + รหัสผ่าน) — **สำรองเก็บไว้** ต้องใช้กุญแจเดิมทุกครั้งที่ออกรุ่นอัปเดต และ **ห้ามเผยแพร่/ห้าม commit ขึ้น GitHub สาธารณะ**

## การใช้งานกับ XAMPP
1. วางโฟลเดอร์นี้ใน `htdocs` (เช่น ในโปรเจกต์ `3.6_CV-pytorch/`)
2. เปิด `http://localhost/<path>/2026-10-16-durian-leaf-app/` บนคอมพิวเตอร์
3. มือถือในวง LAN เดียวกัน: เปิด `http://<IP เครื่องคอม>/<path>/...` ใช้ถ่าย/เลือกรูปได้ แต่ **โหมดกล้องสด** การติดตั้งเป็นแอป และการใช้ออฟไลน์ ต้องเปิดผ่าน HTTPS (หรือ localhost) ตามข้อกำหนดความปลอดภัยของเบราว์เซอร์
   (ทางเลือก: อัปโหลดโฟลเดอร์ขึ้นโฮสต์ที่มี HTTPS เช่น GitHub Pages)

## ข้อจำกัด
- โหมดกล้องสดทดสอบด้วยกล้องจำลองในเบราว์เซอร์ (ป้อนวิดีโอจากรูปชุดทดสอบ) เปลี่ยนผลตามภาพได้ถูกต้อง ~25 มิลลิวินาที/ภาพ แต่ยังไม่ได้ทดสอบกับกล้องมือถือจริง
- APK ยังไม่ได้ทดสอบบนมือถือจริง (ตรวจโครงสร้างและลายเซ็นแล้ว) ควรลองติดตั้งบนเครื่องจริง 1–2 รุ่นก่อนแจกจ่าย
- ชุดทดสอบเล็ก (34 รูป) ยังไม่ได้ทดสอบกับรูปจากสวน/กล้องอื่น
- รู้จักเพียง 4 กลุ่ม อาการอื่นอาจถูกทายผิด
- คำแนะนำสารเคมีมาจาก `configs/model_config.json` ควรตรวจสอบกับผู้เชี่ยวชาญก่อนใช้
