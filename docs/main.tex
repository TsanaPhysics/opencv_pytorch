\chapter*{คำนำ}
\addcontentsline{toc}{chapter}{คำนำ}

เอกสารคำสอนและคู่มือวิชาการฉบับนี้ จัดทำขึ้นเพื่อรวบรวมองค์ความรู้ด้านการบูรณาการเทคโนโลยีคอมพิวเตอร์วิทัศน์ (\textbf{Computer Vision}) และการเรียนรู้เชิงลึก (\textbf{Deep Learning}) เข้ากับงานพยาธิวิทยาพืช (\textbf{Plant Pathology}) โดยมุ่งเน้นการแก้ปัญหาโรคใบทุเรียนซึ่งเป็นพืชเศรษฐกิจหลักของภาคตะวันออกและประเทศไทย

จุดเด่นของคู่มือฉบับนี้คือการออกแบบกระบวนการเรียนรู้แบบ \textbf{No-Code \& Beginner-Friendly} ที่ช่วยให้ผู้เริ่มต้นและผู้ที่ไม่มีพื้นฐานการเขียนโปรแกรม สามารถสร้าง พัฒนา และประยุกต์ใช้โมเดลปัญญาประดิษฐ์ตรวจโรคพืชบนสมาร์ทโฟนได้จริง ผ่านการคลิกทำงานบน Google Colab และการนำโมเดลน้ำหนักเบา MobileNetV3 ไปเชื่อมต่อกับแอปพลิเคชันสมาร์ทโฟน พร้อมเทคโนโลยี Explainable AI (Grad-CAM) ที่แสดงภาพความร้อนชี้ตำแหน่งรอยโรคอย่างชัดเจน

ผู้เขียนหวังเป็นอย่างยิ่งว่า เอกสารฉบับนี้จะเป็นประโยชน์ต่อนักศึกษา เกษตรกรชาวสวนทุเรียน นักวิจัย และผู้สนใจในการพัฒนานวัตกรรมเกษตรอัจฉริยะอย่างยั่งยืน
